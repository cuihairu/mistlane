# Protocol contract recovery

Status: recovered on 2026-11-21 from the committed game-fogs schema binary `game-fogs/game/proto/sproto.spb` (game-fogs commit `37b640a`). This recovers the **definitions** of the legacy business protocol; it does not claim the original generation flow, and the original text source, generation script and official client bindings remain absent. Cross-language page: [简体中文](./zh/protocol-contract-recovery.md); recovery evidence: `contracts/fogs-sproto-schema.txt`; reproducer: `tools/sproto_dump.c`.

## What was recovered

The committed compiled schema decodes to a complete business protocol contract:

- **646 RPC protocols**, each with its numeric id (tag), request type and response type (server→client pushes have no request type; client→server one-ways have no response type).
- **1421 data types** — the request/response bodies plus the referenced struct, array (`*Type`) and map (`*Type[key]`) types.
- **4245 fields** across those types, each with its field number (tag) and type.

Example (`contracts/fogs-sproto-schema.txt`):

```
AC_Broadcast.request
	tp (0) integer
	actid (1) integer
	edTime (2) integer
...
OmAuth (30001) request:OmAuth.request response:OmAuth.response
```

## Method

The `.spb` file is a compiled sproto schema (the format defined by `game-fogs/3rd/sproto/sproto.c`). It is decoded with the vendored sproto decoder via a small dumper (`tools/sproto_dump.c`) that calls `sproto_create` + `sproto_dump`; no Lua interpreter or host layer is involved. The dump is the reference decoder's own output, so it is an authoritative representation of the compiled schema.

## Verification

- **Name→id cross-check:** every one of the 646 protocol ids in the schema matches `game-fogs/game/proto/Protocol.lua` exactly — 0 missing, 0 extra, 0 mismatches. `Protocol.lua` is an independently generated artifact (`--Generated by sprotodump. DO NOT EDIT!`), so this is an independent consistency check.
- **Type references:** 0 unresolved request/response type references; 0 unresolved struct field type references (after stripping `*` array and `[key]` map markers); all fields resolve to a declared type or a primitive (`integer`, `boolean`, `string`, `double`).
- **Shape:** 646 protocols / 1421 types / 4245 fields; 69 protocols carry no request type (pushes), 151 carry no response type; 638 fields are array-typed, 152 are map-keyed.

## Provenance and missing items

- **Artifact source:** `sproto.spb` and `Protocol.lua` are **committed** to game-fogs at `37b640a`; `game/Data/Data.lua` loads the binary into the sproto loader slot at startup. `Protocol.lua`'s header names **`sprotodump`** as its generator.
- **Missing — original text source:** no `.sproto` text file exists anywhere in game-fogs; the schema survives only in compiled form.
- **Missing — generation script:** no build rule or script that ran `sprotodump`/the sproto compiler is present in game-fogs; the generator tool is identified but the build step that invoked it is not.
- **Missing — official client bindings:** the client-side generated protocol binding is a separate client codebase, not part of the server repository from which the schema was recovered.

## Scope caveat

The recovered schema is a **compiled artifact**, not the original generation flow. It carries the RPC names, ids, request/response types and field layouts, but not the original text source's comments, layout, or the build steps that produced the bindings. Per the todo ledger (`todo.md`), this is treated as definition recovery, not as the complete generation pipeline; see todo item 72 and [players, scenes and transfers](./player-scene-model.md#protocol-and-method-contracts-before-abstraction).
