### 二面：浏览器语言自动识别（本轮调查）

- **形态**：文档站 locale 路由（VitePress：`/` = English，`/zh/` = 中文）+ **首页客户端自动识别**：`docs/index.md:1-27` 内联脚本在首次访问根页时按 `navigator.language(s)` 判断，中文浏览器 `location.replace('/zh/')`；手动选择以 `localStorage['mistlane-lang-auto-picked']` 记住并优先于自动判断。
- **探针勘误**：`fleet-url-contract.py` 只扫 config/theme 与静态 HTML，读不到页面内联 `<script setup>`，故报 `auto=None` 属**假阴性**；mistlane 实为全舰队首个确认带自动语言识别的仓。无需立 P2 todo。
- **实测（2026-11-14，playwright + 本地 dist 静态服务）**：locale=zh-CN 打开 `/mistlane/` 后落在 `/mistlane/zh/`（脚本触发 `location.replace`）；locale=en-US 停留 `/mistlane/`。自动识别行为确认工作。
- **需拍板**：是否以本仓形态（localStorage 优先 + 根页 navigator.language 跳转）作为其它仓上自动切换的参考模板——汇总进舰队 G2 报告。
